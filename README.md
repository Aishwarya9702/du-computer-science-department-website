
# Department of Computer Science Website

## University of Delhi

A responsive, multi-page website developed for the Department of Computer Science, University of Delhi, as part of the Web Development and Prompt Engineering practical.

The project demonstrates the use of HTML5 and CSS3 to build a structured departmental website with navigation menus, academic information, an alumni registration form, and a course timetable.

> **Disclaimer:** This is an independent academic project created for educational purposes. It is not an official University of Delhi website.

## Project Objectives

- Develop a departmental homepage using semantic HTML5 elements.
- Design navigation menus with CSS hover-based dropdowns.
- Display faculty information using HTML lists.
- Create an alumni registration form with HTML5 validation.
- Design a weekly course timetable using HTML tables.
- Apply CSS for typography, colors, spacing, borders, and layouts.
- Implement responsive layouts using Flexbox, CSS Grid, and media queries.
- Practice version control using Git and GitHub.

## Website Features

### 1. Department Homepage

The homepage includes:

- University and department header
- Navigation bar with dropdown menus
- Welcome section
- About the Department
- Department gallery
- Department history
- Vision and Mission
- Academic Programmes
- Research Areas
- Faculty information with sample joining dates
- News, Events, and Notices
- Contact information
- Footer

### 2. Navigation Menu

The website includes a horizontal navigation bar with dropdown submenus.

Features include:

- CSS hover effects
- Dropdown navigation
- Internal section links
- Links between webpages

### 3. Department Gallery

Two department-related images are displayed side by side using CSS Flexbox.

### 4. Faculty Information

Faculty information is displayed using HTML unordered lists and styled cards.

Joining dates are sample values used for demonstration and should not be treated as official faculty records.

### 5. Academic Programmes

The website presents information about:

- Undergraduate Computer Science programmes
- M.Sc. Computer Science
- Master of Computer Applications (MCA)
- Ph.D. Computer Science

### 6. Research Areas

Research topics presented include:

- Artificial Intelligence
- Machine Learning
- Natural Language Processing
- Data Science
- Cybersecurity
- Computer Vision
- Software Engineering
- Computer Networks

### 7. News, Events, and Notices

A three-column layout developed using CSS Flexbox.

The announcements are sample content created for the practical and do not represent verified current university announcements.

### 8. Alumni Registration Form

A separate webpage containing:

- Full Name
- Email Address
- Phone Number
- Graduation Batch
- Degree
- Current Designation
- Organization
- About Yourself
- Register and Reset buttons

The form demonstrates HTML5 input controls and client-side validation.

**Note:** This is a front-end demonstration form. It is not connected to a database or registration backend.

### 9. Course Timetable

A sample M.Sc. Computer Science timetable containing:

- Monday-to-Friday schedule
- Subject names
- Time slots
- Lunch breaks
- Practical laboratory sessions
- HTML table elements and colspan
- Responsive horizontal scrolling

The timetable is illustrative and is not an official university schedule.

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/USERNAME/du-computer-science-department-website.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in a browser.

4. Alternatively, use the Live Server extension in VS Code.

5. Navigate between the homepage, alumni registration form, and timetable using the navigation links.

Replace `USERNAME` with your actual GitHub username.

No additional libraries, package installation, or backend setup are required.
